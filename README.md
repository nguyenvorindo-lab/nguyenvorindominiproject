# Mini-Project 1: Trang HTML Chuẩn Đầu Tiên (Phong Cách Báo Điện Tử)

Dự án hoàn thiện trang tài liệu thực hành cấu trúc HTML5 tiêu chuẩn, áp dụng phong cách phân vùng giao diện đa cột trực quan dựa trên ý tưởng từ các trang báo điện tử lớn.

## 📁 Cấu Trúc Thư Mục Dự Án
- index.html: File cấu trúc chính, sử dụng hệ thống thẻ ngữ nghĩa (`<nav>`, `<header>`, `<main>`, `<aside>`, `<footer>`) để phân bố cục 3 cột.
- css/style.css: File định dạng giao diện Flexbox, thiết kế thanh điều hướng màu xanh lá và các khối card tin tức giả lập.
- ui-design.png: Bản vẽ thiết kế UI Layout phác thảo của trang web trước khi code.
- README.md: Tài liệu mô tả và hướng dẫn dự án.

## 📐 Phân Vùng Giao Diện Theo Thiết Kế UI
Trang web được cấu trúc chặt chẽ thành 3 vùng cốt lõi tương ứng với bản vẽ UI đính kèm:
1. **VÙNG 1 (HEADER):** Đóng vai trò làm khu vực nhận diện, chứa thẻ `<header id="vung01-header">` giải thích ý nghĩa tổng quan.
2. **VÙNG 2 (MAIN CONTENT):** Vùng không gian chính (`<main id="vung02-content">`) chịu trách nhiệm hiển thị cấu trúc chi tiết của 4 khối thẻ cốt lõi.
3. **VÙNG 3 (FOOTER):** Nằm ở phần chân trang (`<footer id="vung03-footer">`), lưu trữ thông tin bản quyền và định danh sinh viên.
